# Smart Procurement PDF 2.2 — โรงเรียนจตุรภูมิพิทยาคาร

เว็บไซต์ Static สำหรับสร้างร่างเอกสารจัดซื้อพัสดุ ใช้งานผ่านเบราว์เซอร์โดยไม่ต้องมีฐานข้อมูลหรือระบบล็อกอิน

## เปิดใช้งาน
เมื่อเปิด GitHub Pages ให้กับ repository นี้แล้ว เข้าได้ที่:

https://JAS-tossawat.github.io/dashboard/smart-procurement-v2.2/

## ไฟล์ในโฟลเดอร์
- `index.html` — หน้าเริ่มต้นของระบบ
- `app.gz.b64` — ไฟล์บิลด์ของแอปที่บีบอัดไว้ เพื่อรักษาไฟล์ v2.2 ฉบับที่ตรวจสอบแล้วให้ครบถ้วน

## เปิด GitHub Pages (ถ้ายังไม่ได้เปิด)
1. เปิด repository `JAS-tossawat/dashboard`
2. เข้า **Settings → Pages**
3. ในส่วน **Build and deployment** เลือก **Deploy from a branch**
4. เลือก Branch `main` และ Folder `/(root)) แล้วกด **Save**
5. รอให้ GitHub Pages เผยแพร่เว็บไซต์ แล้วเปิดลิงก์ด้านบน

ระบบเดิมที่ไฟล์ `index.html` ระดับรากยังคงอยู่ ไม่ได้ถูกเขียนทับ การเผยแพร่จาก root จะทำให้ทั้งระบบ Dashboard เดิมและแอปในโฟลเดอร์ย่อยอยู่บนเว็บไซต์เดียวกัน

> หมายเหตุ: ใช้เป็นเครื่องมือช่วยร่างเอกสาร ผู้รับผิดชอบพัสดุต้องตรวจสอบข้อเท็จจริง ระเบียบ และเอกสารก่อนนำไปใช้จริง
