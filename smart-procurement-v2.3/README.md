# Smart Procurement PDF 2.3 — โรงเรียนจตุรภูมิพิทยาคาร

รุ่นนี้ปรับชุดเอกสาร ว 804 ให้ตรงกับแบบฟอร์มที่โรงเรียนแนบมาให้มากขึ้น

## สิ่งที่ปรับปรุง
- รายงานขอซื้อ: รายละเอียดข้อ (1)–(4), ข้อความ “ผ่านหัวหน้าเจ้าหน้าที่”, ช่องความเห็น/ลงนามหัวหน้าเจ้าหน้าที่ และคำสั่งผู้มีอำนาจ
- รายละเอียดคุณลักษณะเฉพาะ: ชื่อโครงการ จำนวนรายการ และข้อมูลอ้างอิงบันทึกข้อความ
- รายงานสรุปผลการจัดซื้อและอนุมัติเบิกจ่าย: ผู้ขาย รายการ/จำนวน/ราคา ยอดรวมภาษีมูลค่าเพิ่มและค่าใช้จ่าย วิธีชำระเงิน หลักฐานรับเงิน วันที่รับมอบและตรวจรับ ลายมือชื่อเจ้าหน้าที่/ผู้ตรวจรับ และคำสั่งผู้มีอำนาจ
- เพิ่มใบติดใบเสร็จรับเงินแยกหน้า สำหรับกรณีเงินสดสำรองจ่าย พร้อมจำนวนเงินตัวเลขและตัวอักษร
- ตรวจระยะเวลารายงานภายใน 5 วันทำการ โดยไม่นับเสาร์–อาทิตย์และวันหยุดที่ผู้ใช้ระบุ
- ตรวจวันที่อนุมัติ/ซื้อ/รับมอบ/ตรวจรับ/หลักฐาน และตรวจยอดเงินสดสำรองจ่ายให้ตรงกับยอดซื้อจริง
